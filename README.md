# Saptarshi Basak - Portfolio Webpage

A responsive and interactive personal portfolio website designed to showcase my resume, skills, and projects as a Data Science and Artificial Intelligence student at IIT Guwahati. 

This repository contains the front-end source code for the portfolio, featuring dynamic content loading and a clean, glassmorphism-inspired UI.

## 🚀 Features

* **Dynamic Content:** Content is separated into `data.js` for easy updates to projects, experience, and skills without altering the core HTML structure.
* **Responsive Design:** Fully styled with custom CSS (`style.css`) to ensure seamless viewing across desktop, tablet, and mobile devices.
* **Interactive Elements:** Smooth scrolling, media controls, and interactive UI components powered by vanilla JavaScript (`script.js`)[cite: 1].
* **Showcase Sections:** Dedicated areas to highlight skills ranging from WebGL and Three.js to C programming and Python automation.
